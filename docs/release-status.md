# Release status

This directory is a local public-review candidate, dated 2026-10-09. No GitHub publication or upload has been performed.

Project name: **Digital Human Interaction Evaluation** (数字人交互效果评测). Repository/package name: `digital-human-interaction-evaluation`.

At the maintainer's request, the candidate now includes the standard [MIT License](../LICENSE), with collective contributor attribution. The license declaration is recorded in the package metadata and citation file. Original notebook authorship, code ownership and authority to redistribute the adapted team code still require confirmation before public release. Adding a license file is not evidence that all original contributors have granted those rights.

The declaration applies to the software candidate and its accompanying documentation and independently generated demonstration assets. It does not relicense the related publications, real participant data, recordings or external third-party software. The ECSCW article's CC BY 4.0 license does not automatically establish rights in every separately archived code or data file.

The candidate includes adapted/reimplemented analysis utilities, newly authored validation and packaging, and independently generated synthetic examples. It excludes raw questionnaires, participant metadata, keep lists, interviews, subtitles, recordings, identity mappings, private access links, archived notebook outputs, publication PDFs, third-party assets and the private file-review report.

Scientific release limitations are documented in [methods](methods.md). In particular, this is a demonstration of the available notebook profile, with unresolved correspondence to the final paper. It should not be advertised as verified reproduction of published numerical findings.
